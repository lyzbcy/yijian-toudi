# 一键投递安装说明

## Windows v0.5.26候选
先核对安装包SHA256。双击NSIS后选择本用户安装位置，通常默认LOCALAPPDATA/Programs/yijian-toudi；桌面快捷方式可选，开始菜单始终保留。完成页可取消立即打开，不会强制固定任务栏。

本机已实际在自选中文目录安装26、普通入口打开可见窗口、启动器自动检测、桌面选项0/1重装与卸载，再恢复原链接。默认目录交互页和自动旧升新仍待独立验收，不把同版本重装称为自动升级。当前候选未公开；见doc/progress/2026-10-04-windows-install.md。

卸载保留用户数据；清理个人数据需自行备份并单独操作。候选NotSigned，不宣称Windows代码签名通过。官网保存/投递仍逐站实测。

## macOS v0.2.0历史内测版

本内测包未使用 Apple Developer ID 签名。

系统要求：Apple Silicon Mac，建议 macOS 13 或更高版本。

## 推荐安装

1. 解压 ZIP。
2. 双击 `一键安装.command`。
3. 按系统提示输入本机管理员密码。
4. 脚本会把 `一键投递.app` 安装到“应用程序”、移除 quarantine 属性并启动应用。

## 手动安装

也可以把 `一键投递.app` 拖进“应用程序”。如果首次打开被系统阻止，请前往“系统设置 → 隐私与安全性”，确认打开此应用。

## 隐私

简历、招聘邮件摘要、浏览器登录态与 Agent Token 默认只保存在本机。QQ 邮箱连接应使用 IMAP 授权码，不要填写邮箱登录密码。

备份文件不会包含 Agent Token、邮箱授权码或招聘网站登录态。腾讯简历保存和岗位最终提交由用户在可见网页中确认；其他公司的简历与投递仍在逐站适配。
