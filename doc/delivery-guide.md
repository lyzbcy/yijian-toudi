# 一键投递候选体验与录制准备

适用候选：v0.5.45 Windows x64 与 macOS arm64/Intel。当前未正式发布，完整交付尚未达标；Mac完整ad-hoc签名、CLI手动升级及原生fixture自动更新事务已验，用户信任、公证和公众正式升级仍待完成。

## 安装和第一次使用

1. 从作者正式 GitHub Release 取得对应平台安装包与 SHA-256 文件，不使用来历不明的转载包。当前候选在本机 `release/yijian-toudi-setup-0.5.45.exe`，正式下载地址尚未发布。
2. Windows 可用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<安装包路径>'` 比对校验文件。候选未完成签名发行验收，Windows 的信任提示和签名状态必须在实际分发说明中如实披露。
3. 启动安装向导，选择安装目录与是否创建桌面快捷方式；开始菜单入口保留。完成后启动软件，选择校招/社招/实习方向。
4. 在“我的简历”填写本人真实资料，多段教育/工作/项目经历各自添加；保存后切换页面并重开软件确认内容仍在。敏感信息和登录会话保存在本机。
5. “招聘项目”刷新岗位后按公司/城市/方向筛选，把适合的岗位加入购物车。部分失败会持续显示失败公司，并保留已有岗位；设置页分开最近尝试与完整成功时间。所有请求正常但没有岗位会显示查询完成；不要把样本岗位说成官网实测。
6. 从公司与邮箱页或简历同步入口登录本人招聘账号；检查官网资料和附件，必要时手动接管。扫码和验证码由本人完成；界面“打开/填写”不等于官网保存或成功投递。
7. 最终申请/投递必须检查岗位和官方回执，未观察到成功不能记为已投递。平台限制、验证码或 403 应停止并复核，不继续刷请求。
8. 连接 AI Agent 时通过“复制接入 Prompt”取得私有凭证；录像只拍遮罩的界面，不拍复制后的内容、真实简历、登录二维码或邮箱授权码。

## 升级、备份和恢复

- 在设置中先导出备份；更新时结束正在进行的官网工作区/批量任务。
- 实际注册安装的 Windows x64 版可直接安装更新。Mac当前候选仅在可写的Applications安装位置启用；源码预览、便携/下载/只读位置继续手动安装。
- 更新检查必须是较新的正式版本、匹配架构的唯一安装包以及对应 SHA-256。下载校验后再确认安装；失败提示应保留，不能只凭进度 100% 推断升级成功。
- 安装助手就绪并确认交接后才退出旧软件；重开界面的版本、简历、附件、登录会话及 API 配置需复核。卸载默认保留本机用户资料。
- 当前Windows真实44→45直接用封存44助手升级，无模板覆盖，桌面关闭8组/开启且确认完成9组和默认NSIS6组通过；43故障恢复/运行中保护按原范围保留。Mac两架构45→46样本事务各10组，含实际16秒慢预检对照；46与正式URL响应均为样本。Mac ready最多等待60秒时旧软件保持运行。真实账号、用户信任及公众正式升级另验。
