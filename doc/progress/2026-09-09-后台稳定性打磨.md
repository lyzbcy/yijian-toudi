# 2026-09-09 后台稳定性打磨

## 范围与执行方式

按用户要求，在 Windows 后台测试，不显示前端窗口，不操作用户正在使用的浏览器。安装锁文件对应的依赖，使用 Electron 43.2.0；所有界面测试使用临时 userData，主窗口与登录子窗口隐藏，Agent API 使用临时端口，关闭测试启动时的自动岗位刷新。外部站点仅匿名读取公开岗位；未保存真实简历、未投递、未发送消息。

本次修改源码，没有替换 release 中的既有安装包，也没有修改用户个人资料。进入任务时已有五个 macOS .command 文件的工作区改动，予以保留。

## 已修复的问题

1. 京东请求错误地发送 JSON 和 pageNo，服务器忽略后一直返回第一页。根据官网 job-info-index.js 改成表单编码与 pageIndex；优先使用公开岗位名称。
2. 美团 pageNo/pageSize 应在 page 对象内。原请求重复返回第一页且去重后无法退出；改为官网实际参数，增加重复页失败保护，部门数组归一化成文本。
3. 字节、小米令牌刷新成功后仍保留旧 HTTP 405 状态，导致成功重试被误判失败。
4. 字节、小米岗位列表不是全局按日期排序；遇到整页旧岗位就提前退出会漏抓。改为持续扫描到列表结束/返回总数/扫描上限（10,000 条），保留既有返回数量上限。主流程每页请求 100 条，减少往返。
5. 六厂请求错误、返回结构异常不能当作成功空数组写回；失败保留原数据。京东、美团未适配校招方向明确报错，不能用空数组冒充成功。
6. 网络响应中断及时拒绝；除空闲超时外增加每个 HTTP 请求 30 秒总时限。
7. 重复发起岗位刷新共用一个执行过程；结果去重，保留没出现在新列表中的收藏；失败任务不更新成功刷新时间，部分失败明确告知。
8. 腾讯中文日期转换成 UTC 后可能少一天，改为保留官网日历日期。
9. 旧 profile 的保存请求不能覆盖刚切换到的另一份简历，返回明确冲突错误。
10. 新建/删除简历前保存当前输入；切换、新建、删除使用本地写入锁并处理失败。
11. 修复简历标签嵌套 button 导致浏览器重排结构，保留键盘切换操作。
12. 简历保存成功后按新内容计算完整度；profile ID 改用 UUID，避免同毫秒创建撞号。
13. 数据保存/备份恢复失败时恢复原内存数据，防止界面和磁盘不一致；恢复迁移完成后再一次性写盘。
14. Agent API 更新 basic/skills/extras 原先误写入 profile，界面读取不到；改为正确更新共享区域，支持受限的点路径字段，校验经历类型。
15. Agent API 端口占用后可以重新启动，并发启动等待同一次监听结果。
16. UI 测试更新新增游戏经历按钮的断言，移除多简历测试的失败自动重试。纠正原测试中“把 A 的编辑写入 B”和“姓名写入 profile.basic”的错误预期。

## 可复用命令

- pnpm test:background：无前台窗口运行单元、静态和八组界面回归；每组日志和 JSON 报告保存到 test-output。失败停止，不以重试隐藏问题。
- pnpm test:live-jobs：匿名官网社招读取验证，持续时间受网络与站点响应影响。

## 尚未完成的验收与口径

后台测试通过率不等于产品真实 bug 率。尚无生产操作总量、缺陷定义与代表性场景分布，不能宣称整体 bug 率低于 1%。本次证据仅覆盖上述代码路径和真实只读岗位请求。

真实账号的登录、验证码、简历保存后回读、最终投递、邮箱授权后的同步仍需另行验收；不通过后台模拟冒充外部写入成功。部分校招适配和跨平台签名/发行问题仍见 doc/未决问题.md。本机测试不证明 macOS 安装包运行结果。
