# 校招轨道真站验收（2026-08-18 晚）

## 背景

用户明确 MVP 只做校招。全平台校招简历页逐一真站验证（无 CDP 独立运行，真实分区）。

## 校招 URL 校准（platform-manifests.cjs）

- 腾讯校招：`resume.html` 是查看态（1 输入框）；真实编辑页 `join.qq.com/resumeedit.html`（187 输入框）
- 阿里校招：旧 `personal-center` 已 404（用户看到的 Whitelabel 白屏根因）；真实页 `/campus/personal/resume`（SSO 回跳为 http，已由 http→https 自动升级修复承接）
- 默认 recruitType：social → campus（用户数据已切换）

## 引擎升级：同页序号定位

美团（mtd）/腾讯校招（el）组件的输入框没有 id/name，旧规则全部转人工。新增第三种定位方式：高置信 label 匹配 + 同页同序号（inspect 与写入同页面状态，复刻 INSPECT_FORM_FIELDS 的控件筛选保证序号对齐），写入后仍有延迟回读核验兜底。腾讯校招因此从 0 → 5 个核验字段。

## 未决（转未决问题.md）

字节/小米校招简历页表单不渲染，需要下季校招开放或人工在页面内探索真实入口后校准。
