# 2026-07-25 · v0.2.0 内测版

## 版本目标

把已有 MVP 升级为可公开下载的 macOS 内测版，重点补齐真实能力说明、用户确认边界、隐私告知、备份恢复和 Agent 防重复执行。

## 已实现

- 阶段一腾讯审核式闭环，详见 [2026-07-25-腾讯闭环.md](2026-07-25-腾讯闭环.md)。
- 首次启动显示本机数据、邮箱授权码、Agent API 和最终提交的隐私边界。
- 本地备份排除 Agent Token、邮箱授权码、登录态、幂等记录和审计记录。
- 恢复备份前自动保存当前数据；恢复不会覆盖当前机器的 Token、授权码和网站 session。
- Agent 写命令必须携带 `Idempotency-Key`，相同动作重试不会重复执行。
- Agent 操作审计只保存动作、来源、目标、状态和截断消息，最多 200 条。
- 应用、README、介绍页和网页缓存版本统一为 `0.2.0` / `PAGE_V=2`。

## 发布前验证清单

- 单元测试、项目静态检查、Electron 桌面冒烟测试。
- GitHub Pages 介绍页桌面与移动端冒烟测试。
- macOS Apple Silicon 应用目录启动测试。
- ZIP、DMG、安装说明与 SHA256。
- GitHub Release 资产和介绍页下载链接。

## 诚实边界

- 六家公司“已适配”指岗位抓取，不代表六家公司都已完成简历填写和投递。
- 腾讯简历与投递指“软件自动准备、用户最终确认”，不代表无人值守提交。
- 没有用户账号授权时，不把真实登录、验证码或最终提交写成自动测试通过。
