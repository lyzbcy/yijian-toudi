# 2026-07-25 · 腾讯审核式闭环

## 本轮完成

- 把原先不可见、执行后立即销毁的腾讯自动化视图改为主窗口内的可见浏览器工作区。
- 登录、简历核对、投递核对统一复用 `persist:tencent` 会话，关闭前刷新 cookie 与本地存储。
- 统一简历的 41 个字段都有稳定字段键与匹配关键词；自动填写会返回“已填写/需手动检查”报告。
- 腾讯简历填写完成后保留官网页面供用户核对，软件不点击官网保存。
- 腾讯投递一次准备一个岗位，打开申请流程后等待用户在官网确认，软件不点击最终提交。
- 只有页面明确出现“申请成功/提交成功/投递成功”等证据时，岗位才从购物车移入已投递。
- 登录失效、待确认、取消、未知页面和失败岗位保留在购物车，不再被误记为成功或整车清空。
- 公司购物车超过 `maxActive` 限制时阻止启动，并显示人工维护的规则说明。
- Agent API 对审核式结果增加 `requiresReview`，接入 Prompt 明确禁止把待确认描述为已完成。

## 真实账号验收边界

当前环境没有用户腾讯账号授权，自动测试不会登录、不会处理验证码、不会保存腾讯简历、不会提交真实岗位。真实账号验收步骤是：

1. 在“公司与邮箱”中打开腾讯并完成登录。
2. 回到“我的简历”点击“更新到腾讯”，核对工作区中的字段命中情况。
3. 不保存也可以结束核对；如需保存，由用户在腾讯官网点击保存。
4. 把一个腾讯岗位加入购物车并启动投递。
5. 软件打开申请流程后，最终提交由用户在腾讯官网确认。
6. 点击应用顶部“完成投递检查”；只有腾讯页面存在明确成功提示时才进入已投递。

## 已知限制

- 腾讯页面结构仍可能改版；无法识别时会降级为手动检查，不会盲目填写或提交。
- 当前只对首段教育、工作和项目经历生成自动填写计划；页面若要求新增多段经历，需要在可见工作区手动补充。
- “完成投递检查”基于页面明确成功文案判断；没有证据时岗位继续保留在购物车。
- 其他公司的简历填写和投递仍是 `unsupported` 或手动流程，下一阶段按能力矩阵逐站扩展。
