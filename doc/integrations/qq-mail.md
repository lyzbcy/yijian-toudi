# QQ 邮箱招聘信息同步

## 已实现

- 连接 `imap.qq.com:993`，使用 TLS。
- 使用 QQ 邮箱 IMAP 授权码，不使用账户登录密码。
- 默认读取最近 80 封邮件。
- 根据主题、发件人和正文判断是否为招聘相关邮件。
- 将邮件分为 Offer、面试、测评、流程中、结束与其他。
- 授权码用系统安全存储加密后再写入本地状态。

## 用户准备

用户需要在 QQ 邮箱网页设置中开启 IMAP 服务并生成授权码。授权码属于敏感凭据，不应粘贴到聊天、日志或 issue。

## 仍需补充

- 首次连接向导与 QQ 邮箱设置的图文引导。
- 增量同步游标，避免每次重复扫描。
- 附件与日历邀请解析。
- 更完善的公司与岗位实体识别。
- 使用真实账号进行端到端测试（必须由用户提供临时授权且测试后撤销）。
