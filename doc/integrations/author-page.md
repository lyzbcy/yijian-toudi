# 软件内作者页

v0.5.46候选统一设置、侧栏、浮动“关于捞鱼”入口为`page-author`，展示本地头像、简介及粉丝群、赞赏、微信表情包原始素材，没有打开外部主页的附带动作。

三张二维码图片均为有标签的按钮，鼠标点击或Enter打开`authorQrDialog`，保留原文件和比例。关闭按钮或Escape返回作者页，原生dialog恢复触发按钮焦点。源码专项检查1100/1280/1440宽度、图片加载、无横向溢出、三入口同页、一个窗口、无外部打开请求及键盘关闭。
