# Mac桌面自动更新候选

当前源码0.5.41已实现，两架构原生fixture事务各6组通过（37193622432）；不等于公众正式升级或用户Gatekeeper验收。0.5.40封存包没有Mac自动安装入口，不修改旧包或旧证据。

更新器继续只接收正式较新Release、唯一匹配架构ZIP和精确SHA-256。安装入口限实际打包应用、`/Applications`或本用户`~/Applications`的直接子应用，资料在应用外，目标目录可写，当前bundle版本/标识/完整资源签名和架构均匹配。DMG、下载目录、只读位置、源码预览和便携临时位置继续手动更新。

安装前重新计算下载hash，检查ZIP中央目录和内部软链接，拒绝穿越、重复条目、额外根目录和指向应用外的软链接，再解压并验证新版身份、架构与严格资源签名。完整新包放在安装目录同级，互斥锁防止两个更新助手同时替换。

静态Bash助手通过JSON接收路径，不把路径拼成Shell或AppleScript代码；不提权、不移除quarantine。助手验证旧包/新包和下载hash后先写ready，主进程保存本机资料和Cookie并commit，收到commit-ack后才退出。助手等待旧进程和该bundle的子进程退出，原子改名保留完整旧包、放入新包，验证成功后通过系统open启动同一资料目录。可见新版自行匹配nonce/版本/可执行文件并写restarted；安装100%不能代替重启确认。

替换或启动失败时保留失败包并恢复旧包，结果标记failed/restored，重开旧应用。资料目录和附件不参与包替换。成功后保留旧bundle用于维护者恢复，不自动删除备份。Developer ID/公证/端用户Gatekeeper仍是独立门槛，ad-hoc资源完整性不代表可信发行。

`test/macos-auto-update.cjs`在唯一CI Applications目录执行实际当前安装包，另在忽略目录构建下一版本样本ZIP，使用受控正式URL响应走实际IPC下载/hash/helper/退出/改名/open/重启确认。测试包括ready后abort、测试worker显式注入替换后失败以验证真实恢复、资料/API凭据/附件字节/样本持久Cookie保留。下一版本和网络响应是测试样本，不算公众正式升级；截图为自动重启后再次可见冷重开的界面。真实账号、原生Gatekeeper批准和官方公网升级仍待验。
