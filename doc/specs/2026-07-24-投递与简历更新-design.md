## 目标

用腾讯做第一个完整闭环：用户登录腾讯 → 软件自动填简历 → 购物车选岗 → 自动投递 → 用户确认提交。

## 架构

### 数据流
```
用户在软件内填简历（本地） 
  → 点"更新到腾讯" 
  → 用已登录 session 打开腾讯简历页（WebContentsView）
  → 自动填写表单字段（executeJavaScript）
  → 用户确认保存
  
用户在购物车选岗位 
  → 点"一键投递" 
  → 对每个岗位：打开岗位详情页 → 点"申请岗位" → 填表 → 用户确认提交
```

### 核心依赖
- **嵌入式登录**（已实现）：投递/填简历前检查登录态，未登录弹引导
- **WebContentsView**（已实现）：打开腾讯页面执行 DOM 操作
- **字段映射**（待做）：软件简历字段 → 腾讯表单字段的映射表

## 子项目 1：腾讯简历填写适配器

### 新建 electron/adapters/tencent-fill.cjs
- `fillTencentResume(resume, session)`：用已登录 session 打开腾讯简历页，自动填表单
- 字段映射表（需实测腾讯简历页 DOM 确认选择器）：
  ```
  软件字段 → 腾讯选择器
  resume.basic.name → input[name="name"] 或 #resume-name
  resume.basic.phone → input[name="phone"]
  resume.basic.email → input[name="email"]
  resume.education[0].school → 教育经历块的学校输入
  ...（实测时补全）
  ```
- 填表用 `view.webContents.executeJavaScript()` 注入 DOM 操作
- **不自动保存**——填完暂停，用户在页面上确认后自己点保存

### 前端
- 简历页加"更新到腾讯"按钮
- 点击后：检查登录态 → 打开腾讯简历页 → 自动填表 → toast"已填写，请确认后保存"

## 子项目 2：腾讯投递适配器

### 新建 electron/adapters/tencent-apply.cjs
- `applyTencentJob(jobUrl, session)`：用已登录 session 打开岗位详情 → 点"申请岗位" → 处理投递表单 → 用户确认
- 投递按钮选择器：`.default-btn`（实测确认）
- 投递流程可能有：确认弹窗/补充信息/简历选择 → 每步都暂停等用户

### 购物车"一键投递"改造
- applyCart 改为：检查每个岗位公司的登录态 → 已登录的自动走投递流程 → 未登录的跳过 + 提示
- 投递在 WebContentsView 里进行，用户能看到每一步

## 关键约束（诚实边界）
- **不绕过登录**：投递/填简历前必须用户已登录
- **不自动提交**：所有最终提交动作等用户确认（agent.md 第35行"必须让我确认"）
- **每家结构不同**：腾讯做完后，其他家需要单独适配

## 技术风险

- 投递流程可能有验证码（agent.md 提到滑块验证码问题）
- 腾讯可能有反自动化（检测快速填表）
