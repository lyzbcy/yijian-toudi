# 路线图

## P0 · 单站闭环

- 选择 1 家招聘网站建立首个真实适配器。
- 真实岗位全量抓取、去重、字段清洗。
- 登录态检测与用户接管。
- 本地简历到平台字段的完整映射。
- 最终投递前的差异预览与确认。
- 网站改版检测和适配器健康检查。

## P1 · 可发布内测

- 建立 GitHub 仓库、Pages、Actions、Release。
- 配置仓库更新源并验证一键更新。
- 生成正式图标、DMG、ZIP 与 SHA256。
- 增加首次启动向导、隐私说明和数据备份恢复。
- 对 Agent API 增加命令幂等键和操作审计。

## P2 · 扩展平台

- 新增 3-5 家招聘网站适配器。
- 简历版本、岗位投递历史与漏斗分析。
- 邮件增量同步、日历提醒。
- Windows NSIS 打包与安装测试。

## 发布门槛

“支持某公司”必须同时满足：岗位抓取、登录恢复、简历字段映射、失败可见、最后一步确认、至少一次真实账号端到端回归。只实现了打开网页不能写成“已支持”。
