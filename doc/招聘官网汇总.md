# 各公司招聘官网网址汇总

本页集中记录本项目涉及的所有公司招聘官网入口（社招首页、校招首页、简历页、抓取用到的 API 端点），方便适配前快速核对、改版时定位。

> 与 [integrations/大厂清单.md](integrations/大厂清单.md) 的分工：那份偏「适配进度 + 字段映射 + 已知坑」，本份偏「网址速查表」。两份信息源一致，URL 变更时两份都要改。

> 第一、二部分的适配与速查 URL 从 `electron/adapters/*.cjs` 源码或既有调研逐条核对，采集日期 **2026-07-26**。第三部分另以人工录制为证据。招聘站点偶尔改版，再次核对前不要直接当作可用事实。

> **简历更新录制说明**：第三部分来自 2026-07-26 在 Microsoft Edge 中的人工操作录制。录制只证明当时看到的入口、控件和操作结果，不等于已完成自动化适配；其中的姓名、证件、手机号、邮箱、验证码等个人信息均不记录。

## 三、简历更新操作（2026-07-26 录制实测）

### 统一安全边界

1. 本节只描述**更新账号内简历资料**，不授权申请或投递任何职位。
2. `保存`、`更新`、`完成`、`保存并预览`等按钮在确认只影响个人简历时才能点击；`提交简历`、`申请职位`、`确认投递`、`去选择职位`不得作为保存按钮使用。
3. 短信/邮箱验证码、扫码登录、账号注册、密码设置、隐私协议、真实性声明和人才库授权由用户本人处理，不记录具体内容。
4. 上传并解析后必须逐段核对，尤其检查日期、学历、工作/项目经历和联系方式；解析成功不代表内容正确。
5. 每站保存后应重新进入简历预览或编辑页复核。录制中没有完成复核的站点均标为“路径已确认”，不能写成“更新已验证”。

### 腾讯社招

- **进入路径**：社招首页 → `我的简历` → 无简历时点 `创建简历`；实测落到 `myresume.html` 和 `resume.html?operType=1`。
- **更新方式**：可上传本地简历自动解析，也可手动编辑。录制页面提示文件不超过 6 MB，支持 PDF、DOC、DOCX、TXT、JPG、PNG。
- **页面分区**：联系信息、工作意向、工作经验、学历、补充信息、作品/附件、作品链接和个人主页链接。
- **保存**：补齐必填项，用户本人确认隐私政策后点击 `保存`。录制中曾因必填项/协议未完成而再次编辑，未出现独立的成功页，因此保存后必须返回 `我的简历`复核。
- **维护提示**：源码适配器仍记录 `jobresume/resume.html`，与本次人工实测入口不同，后续做自动填写前要重新核对跳转链路。

### 腾讯校招

- **进入路径**：校招首页 → 右上角账号菜单 → `我的简历` → `编辑简历`，对应 `resume.html` 和 `resumeedit.html`。
- **更新内容**：简历附件、照片、基本信息、教育、实习、项目、获奖、语言、作品/个人主页和其他关键信息；支持“无实习经历/无项目经历/无获奖信息”等选项。
- **高风险按钮**：录制中点击页面底部 `提交简历` 后，直接进入职位“提交成功”页面。它不是普通保存按钮，单纯更新简历时必须停在这里，不能点击。
- **当前结论**：没有实测到与职位投递解耦的全局保存动作。自动化只能帮助填写并停在最终按钮前；是否投递必须由用户针对具体职位另行授权。

### 百度校招

- **进入路径**：校招岗位页 → 登录 → `个人中心` → `创建/编辑简历`，编辑页为 `https://talent.baidu.com/jobs/resume/create`。
- **登录**：录制中账号登录后还需要 6 位验证码；验证码由用户本人完成。
- **更新方式**：点击 `上传简历` 选择文件；已有内容时会询问是否 `覆盖`。覆盖后自动解析，再手动检查下拉项、起止时间、绩点、地点、经历描述等字段。
- **保存**：点击页面底部 `保存`；若随后出现非必要的补充弹窗，可选 `稍后再说`。保存后回到个人中心复核。
- **已知坑**：解析后仍有大量选择框和日期字段需要人工确认；不要只看上传成功提示。

### 字节跳动校招

- **进入路径**：校招岗位页 → 账号菜单 → `我的简历` → 编辑，分别为 `/campus/resume/view` 和 `/campus/resume/edit`。
- **更新方式**：在编辑页上传文件并解析，然后检查基本信息。
- **页面分区**：基本信息、教育经历、实习经历、工作经历、项目经历、作品、获奖、证书、语言能力、自我评价等；各段通过 `添加` 新增。
- **完成**：录制中页面底部为 `完成`。点击后仍需重新打开 `/campus/resume/view` 核对是否保存及解析是否准确。
- **风险**：编辑页可能包含证件信息等高敏字段，自动化不得记录或回显具体值。

### 小米校招

- **进入路径**：校招岗位页 → `登录` → `/campus/resume/view` → `/campus/resume/edit`。
- **登录**：手机号 + 短信验证码；验证码由用户本人完成，并由用户确认登录协议。
- **更新方式**：点击 `选择文件` 上传并解析简历，再编辑年龄、基本信息和各类下拉项。
- **页面分区**：附件简历、基本信息、教育经历、实习经历、项目经历、作品、获奖、语言能力、自我评价。
- **完成**：页面底部为 `完成`。小米与字节使用相近的 ATS，但字段和入口不可直接假定完全相同；完成后要返回预览页复核。

### 京东校招

- **进入路径**：校招首页 → 登录/微信快捷登录 → 账号菜单 → `我的简历`，地址为 `https://campus.jd.com/#/resume?type=present`。
- **更新方式**：更新简历附件时选择文件，并确认 `是，上传并解析`。
- **页面分区**：基本资料及多组 `+ 添加` 区块，包含教育/校园经历、项目经历、语言/证书/技能、证书附件和作品集等。
- **保存**：补齐解析后遗留的日期和必填项，用户本人处理协议复选框后点击 `保 存`。
- **复核**：保存后重新进入同一路径，检查“简历完成度”和附件名称是否更新。

### 美团校招

- **进入路径**：校招首页 → 个人中心简历 → 编辑；实测编辑页为 `resume-detail?type=campus&mode=edit`，查看态将 `mode` 改为 `view`。

## 维护纪律

1. **源码与录制分开**：第一部分的 API 端点和适配器 URL 必须能在 `electron/adapters/*.cjs` 里找到对应行；第三部分的人工简历路径必须带录制日期和验证状态，不能冒充源码适配。
2. **改版联动**：招聘站点改版后，若影响适配器，同时更新源码和 [integrations/大厂清单.md](integrations/大厂清单.md) 的对应行；若只完成了人工复核，更新第三部分的录制状态。
3. **不冒充可用**：未走完真实抓取/投递实测的站点，不得把 URL 描述为「已适配」，只能写「已调研」或「待适配」。
4. **采集日期**：本页 URL 采集于 **2026-07-26**，超过 30 天再次核对前不要当作可用事实。
