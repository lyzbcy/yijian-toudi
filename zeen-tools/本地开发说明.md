# 一键投递 · 本地开发

## macOS

- 启动桌面应用：双击 `一键启动应用.command`
- 关闭桌面应用：双击 `一键关闭应用.command`
- 预览介绍页：双击 `一键预览介绍页.command`
- 关闭介绍页：双击 `一键关闭介绍页.command`

首次启动会安装依赖，耗时比后续启动更长。当前 Codex 工作区没有全局 Node.js 时，脚本会尝试使用 Codex 自带运行时。

## Windows

- 启动：双击 `一键启动应用.bat`
- 关闭：双击 `一键关闭应用.bat`

Windows 需要预先安装 Node.js 20+。脚本兼容中文项目路径，并使用 UTF-8 代码页。

## 介绍页

默认地址：`http://127.0.0.1:4173/`。启动脚本会在首页返回成功后再打开浏览器。修改 `site/` 后刷新即可看到最新内容。

## 推荐检查

1. 打开招聘项目，确认岗位列表与“演示数据”标签可见。
2. 搜索岗位并收藏。
3. 打开我的简历，填写姓名后保存。
4. 打开连接 AI Agent，确认本机地址和 Prompt 可见。
5. 打开介绍页，确认三组二维码图片均能加载。
