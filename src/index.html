未连接

需要在 QQ 邮箱设置中开启 IMAP，并使用授权码而不是登录密码。授权码使用系统安全存储加密。

不会获取授权码？点这里看步骤
  1. 电脑浏览器打开 mail.qq.com 并登录你的 QQ 邮箱
  2. 点顶部「设置」→「账户」
  3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务」，开启「IMAP/SMTP 服务」
  4. 按提示用手机发短信验证，会得到一串 16 位授权码（不是登录密码）
  5. 把授权码填到下面，点「连接并同步」

支持 163 / Gmail 等其他邮箱吗？目前只接了 QQ，其他邮箱适配在路上。授权码随时可在邮箱设置里关闭。

本机数据备份

            
备份包含简历、岗位、招聘消息和购物车，不包含 Agent Token、邮箱授权码或网站登录态。

            

              
              
            

          

          

            
数据安全与更新

            
你的简历、岗位、邮箱配置等都保存在本机：~/Library/Application Support/一键投递/

            
更新 APP 只会替换「应用程序」里的应用本体，不会清除上述数据，所以更新后不用重填。换电脑时用「备份数据」迁移即可。

            
数据未上传任何服务器。Agent API 只监听 127.0.0.1，仅本机可访问。
