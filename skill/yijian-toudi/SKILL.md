# 一键投递

本 Skill 是本机 API 客户端，不是浏览器引擎。先发现实际能力，再选择所需流程；不把所有参考资料一次读完。

## 每次使用
1. 从安装主目录执行 `node scripts/use.cjs`，读取返回的有效 `version/root/instructions`，而非把引导器出厂version当当前版本。更新检查不等待、不发投递命令；后台更新只影响下一次调用，已运行任务保持原快照。
2. 从APP「连接 AI Agent」取得Base URL，Token仅存私有 `YJTD_API_TOKEN`；GET `/v1/status` 核对运行APP与有效Skill同版本，再GET `/v1/skill` 读取实际操作契约。不匹配不发业务写命令，不自动升级或重启桌面。
3. API只监听127.0.0.1。异机连接、每日定时和异常启动处理读[部署与Boss批量](references/deploy.md)；更新通道/缓存问题才读[静默更新](references/update.md)。

## 按任务选路
| 当前任务 | 操作入口 / 需要读取的资料 |
|---|---|
| 查岗位、简历、消息、已有任务 | GET `/v1/jobs`、`/v1/resume`（脱敏）、`/v1/messages`、`/v1/tasks`；据实际岗位给出匹配理由与事实缺口 |
| 用户事实的最小增量、岗位购物车 | POST `/v1/commands`，写请求带 `Idempotency-Key`；动作与字段以运行APP契约为准 |
| 多企业网申、通用官网、成功后同步管理平台 | [官网Agent协作](references/official-applications.md)：先复用已登录平台/已核对简历，再处理独立官网；CLI `scripts/applications.cjs` 管理持久账本 |
| Boss批量与已授权定时 | [部署与Boss批量](references/deploy.md)：核对账号、演练、上限、互斥和未知回执；`scripts/daily-boss.cjs`只提交任务，不等于已完成投递 |
| 字段失败、简历改版、原窗口续办 | [简历与原任务恢复](references/resume-recovery.md)：诊断、原id查询、专用控件与官网存储核验 |

## 跨流程不变量
- 身份与事实：只使用本次指定账号、简历和确认值；不复用另一客户登录态。不猜日期/证书/薪资单位，不把脱敏数据当匿名。公司题不写成所有公司的共同答案。
- 授权：用户已授权的目标/筛选/数量/时间预算内连续推进，不因完成几家就停等“继续”；不扩展公司范围、费用、通知或日程。验证码/登录/资料缺口暂停该站，继续其他已授权且独立可执行任务；账号级限制、身份错配或全局未知状态按原契约停止。
- 防重：请求重试复用原幂等键；未知任务先查原id/runId/attemptId，不换ID重投。`requiresReview`、`running/stopping`或未确认启动记录不能自行清除；单站障碍与账号级停止分开处理。
- 证据：本机保存、官网保存、正式申请、外部平台同步分别核验。仅真实官网成功回执才登记已投递；previewed、草稿、候选、打开页面都不计成功。账本回执是agent-reported，不是独立官网认证，99%是覆盖目标而非实测结果。
- 恢复：401回APP核对Token；404核对能力/版本；501按未提供能力处理；503/断连保留任务与键，重开后查原结果。不强杀旧窗口、不清登录态、不自动重放提交。

## 可复用任务提示词
```text
先执行本Skill的scripts/use.cjs，读取有效入口并核对APP版本，再读/v1/skill。
按我已授权的账号、筛选、数量和预算选择对应流程；优先复用已登录平台与已核对简历，连续推进但不扩大范围。
阻塞单站记录后切换；未知提交只查原回执；官网成功与外部同步分别核验。
报告新增成功、唯一企业数、同步成功、待补资料和未知项，并附证据引用，不输出凭据。
```

历史发版、开发现场和失败记录留在项目CHANGELOG/doc/progress及原始验证档案，不作为每次操作前置阅读。Skill源码候选与安装/官网实测结果分别验收。

## 邮箱进度管理
在APP公司与邮箱分别连接QQ和江南大学网页邮箱，复用正常网页登录，不收集sid或授权码。每邮箱连接/扫描覆盖与失败独立。用户启用后，软件运行时10分钟同步全部当前范围邮箱。需要历史补导时勾选进度导入再核对全部；岗位不明/多岗位/跨邮箱同公司/旧邮件查看投递管理待核对，不把邮件记录当官网成功投递。

### 投递驾驶舱0.5.89
投递管理顶部阶段流水线点击筛选，下方一键整理待办并按截止时间排序，点卡片打开详情。支持安排时间、完成/忽略/恢复；完成不推进投递阶段。未知日期待确认，仅已同步邮件列表中的明确时间或手动日期作为排序依据；保留双邮箱同步。

### 正文安排与Agent纳管0.5.90
从邮件正文补全安排可自动提取明确时间、收信后时限和链接；开启后正常邮箱同步自动补全，可能按网页正常阅读标为已读。手动安排不覆盖。
Agent投递仍按/v1/applications的ready/授权/receipt契约；只有带真实观察证据的submitted回执自动进入投递管理，不重复登记、不把未知记成功。点击阶段优先显示该阶段项目和待办。

### 右侧待办工作栏0.5.91
左侧项目，右侧顶部待办与同栏下方详情。阶段筛选同时作用于项目/待办，小窗待办优先。区分企业官网网申、站内简历申请、发起聊天；看到聊天或跳转不能登记官网投递成功。

### 智联校园正式网申0.5.92
智联校园读取当前真实可见岗位、导入本机岗位库与Agent正式网申流程见 references/zhilian-campus.md。聊天/平台简历送达/企业ATS分账；成功typed回执自动进入投递管理；历史unknown不重判。
